# O'Clock

A clock that only shows what you're doing now. When a task's time arrives, its slice of the dial lights up with things from that task; when nothing is scheduled, it's just a clock.

Live: https://shuyii0315-arch.github.io/oclock/

Two styles (sticker and hand-drawn), shown on the web and as an iPhone home screen widget. Designed by Shuyi Yuan.

The iPhone home screen image comes from Apple's iOS 27 UI Kit and is used here for presentation only.
